# Nutribio

PWA mobile-first/responsive (React 19 + Vite + TypeScript + Tailwind CSS v4) —
weekly meal plans generated by Google Gemini from bioimpedance data. 100%
frontend, no backend; all state lives in `localStorage` (namespace `nutribio.v1`).
UI language: Portuguese (PT-PT). Code/identifiers/comments: English.

## ⚠️ READ THIS FIRST — Decisions that must NOT be undone

The most critical ones:

1. **No backend, no database, no sync** — data is intentionally single-device
   (localStorage). Do not add a server, accounts, or sync.
2. **Gemini API key lives ONLY in the Settings screen → localStorage.**
   Never bake it into the bundle or read it from env vars in production
   (the user explicitly rejected env vars because they are extractable from
   the shipped JS). `.env.example` is documentation only.
3. **Deterministic nutrition math is local** (`src/lib/calculations.ts`);
   Gemini receives the computed targets and only does the creative work
   (dishes, gram portions, weekly plan).
4. **Regeneration is ALWAYS user-confirmed** (dialog). Never auto-call the
   Gemini API on data changes or app start.
5. **Mobile-first does NOT mean mobile-only.** The layout must adapt: bottom
   tab bar + stacked sections on mobile; left sidebar + multi-column grids on
   desktop (`md+`). The user corrected this explicitly.
6. **Do not widen `vite.config.ts` `server.allowedHosts`** — it is restricted
   to the user's tunnel host (`nbio.loca.lt`) on purpose.
7. **Preserve `profile.excludedFoods`/`observations`** in every profile write
   (editable in Settings/onboarding; other screens must pass them through).

## Commands

- `npm install` — install dependencies
- `npm run dev` — dev server (http://localhost:5173; host allowed: `nbio.loca.lt`)
- `npm run build` — type-check (`tsc --noEmit`, strict) + production build to `dist/`
- `npm run preview` — serve the production build
- `npm run icons` — regenerate PWA icons (Python + PIL, `scripts/generate_icons.py`)

## Quick map

| Path | Responsibility |
|---|---|
| `src/lib/calculations.ts` | BMR (Mifflin-St Jeor + Harris-Benedict), TDEE, calorie ranges, macros, meal split |
| `src/lib/gemini.ts` | Gemini plan generation (structured JSON output, validation, retry, prompt builder) |
| `src/lib/models.ts` | Live Gemini model listing for the Settings dropdown |
| `src/lib/storage.ts` | localStorage keys, defaults, bio record merge/remove, export/import |
| `src/lib/plan.ts` | Plan assembly + query helpers (selected dish, day/week totals) |
| `src/lib/mealTimes.ts` | 5 meal slots + time windows, next-meal helpers |
| `src/lib/hash.ts` | FNV-1a inputs hash (plan cache invalidation) |
| `src/hooks/useStore.tsx` | Global state + persistence + plan generation action |
| `src/screens/*` | Onboarding (3-step wizard), Today, Plan, Progress, EditData (Dados), Settings |
| `src/components/*` | TabBar/Sidebar, forms (Field/NumberInput/TextArea), dialogs, charts, meal cards |
